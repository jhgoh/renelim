# Neutrino Oscillation PDFs

This directory provides RooFit probability density functions for neutrino oscillation analyses.

## NuOscIBDPdf

`NuOscIBDPdf` models the inverse beta decay (IBD) energy spectrum without detector smearing. The prediction for a neutrino of energy $E$ at baseline $L$ is

$$
P(E) = \phi(E)\sigma(E)
\left[1 - \sin^2 2\theta_{13}\sin^2\left(\frac{1.27\Delta m^2_{31}L}{E}\right)
      - \sin^2 2\theta_{14}\sin^2\left(\frac{1.27\Delta m^2_{41}L}{E}\right)\right],
$$

where $\phi(E)$ is the neutrino flux (summed over fuel isotopes weighted by their fractions), $\sigma(E)$ the IBD cross section, $L$ is in metres, and the mass splittings are in $\text{eV}^2$.

### Constructors

Two constructor overloads are provided:

```cpp
// Primary: spectra and cross section as pre-built vectors
NuOscIBDPdf(name, title, x, l, sin13, dm31, sin14, dm41, elemFracs,
            vector<vector<double>> elemSpectsX, vector<vector<double>> elemSpectsY,
            vector<double> ibdXsecX, vector<double> ibdXsecY);

// Legacy: load directly from TGraph objects
NuOscIBDPdf(name, title, x, l, sin13, dm31, sin14, dm41, elemFracs,
            vector<const TGraph*> elemSpects, const TGraph* grpXsec);
```

The legacy constructor converts the `TGraph` data to vectors internally and delegates to the primary constructor.

## BinnedNuOscIBDPdf

`BinnedNuOscIBDPdf` extends `NuOscIBDPdf` by applying detector response smearing and baseline smearing.

In this class, `x` is the reconstructed-energy observable and `xInt` is the true-energy integration variable used for response-matrix convolution.

### Layer 1: Response matrix smearing (core behavior)

First, the model applies an energy-dependent detector response matrix $R(\tilde{E},E)$ to map true energy $E$ to reconstructed energy $\tilde{E}$:

$$
P_{\mathrm{resp}}(\tilde{E}) = \int dE R(\tilde{E},E)\phi(E)\sigma(E)
\left[1 - \sin^2 2\theta_{13}\sin^2\left(\frac{K_{31}}{E}\right)
      - \sin^2 2\theta_{14}\sin^2\left(\frac{K_{41}}{E}\right)\right],
$$

with $K_{ij}=1.27\Delta m^2_{ij}L$ for a fixed baseline $L$.

Because $R$ is provided as a histogram and flux/cross-section inputs are treated as piecewise linear functions, the true-energy integral per reconstructed-energy bin is evaluated analytically using sine/cosine integrals (`ROOT::Math::sinint`, `ROOT::Math::cosint`).

### Layer 2: Baseline smearing (additional geometry effect)

On top of response smearing, the class incorporates finite reactor-core and detector-size effects through a baseline histogram with bin centers/weights $(L_k,w_k)$:

$$
P(\tilde{E}) = \sum_k w_k \int dE R(\tilde{E},E)\phi(E)\sigma(E)
\left[1 - \sin^2 2\theta_{13}\sin^2\left(\frac{K_{31}(L_k)}{E}\right)
      - \sin^2 2\theta_{14}\sin^2\left(\frac{K_{41}(L_k)}{E}\right)\right],
$$

with $K_{ij}(L_k)=1.27\Delta m^2_{ij}L_k$.

This baseline histogram is required for `BinnedNuOscIBDPdf`; generate it with `python scripts/baseline_smearing.py` using the reactor/detector geometry in your configuration.

### Constructors

The class follows the same two-overload pattern as `NuOscIBDPdf`, with additional baseline and response histogram inputs:

```cpp
// Primary: spectra and cross section as pre-built vectors
BinnedNuOscIBDPdf(name, title, x, xInt, l, sin13, dm31, sin14, dm41, elemFracs,
                  vector<vector<double>> elemSpectsX, vector<vector<double>> elemSpectsY,
                  vector<double> ibdXsecX, vector<double> ibdXsecY,
                  const TH1* hBaseline, const TH2* hResp);

// Legacy: load directly from TGraph objects
BinnedNuOscIBDPdf(name, title, x, xInt, l, sin13, dm31, sin14, dm41, elemFracs,
                  vector<const TGraph*> elemSpects, const TGraph* grpXsec,
                  const TH1* hBaseline, const TH2* hResp);
```

### Input notes

- `hResp` is the detector response matrix (e.g. `data/response_gaus.root` generated by `python scripts/response_gaus.py`).
- `hBaseline` is the baseline-smearing histogram and is required (generate with `python scripts/baseline_smearing.py`).
